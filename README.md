# Luxe Stay Booker

Build a modern, premium direct-booking website for my Airbnb rental property.

The website should feel like a high-end boutique hotel / luxury short-stay property, NOT like a generic Airbnb clone.

DESIGN STYLE:

- Modern, elegant, minimalist

- Premium hospitality aesthetic

- Clean typography

- Large high-quality property photography

- Warm and welcoming

- Lots of whitespace

- Subtle animations and transitions

- Mobile-first and fully responsive

- Avoid excessive gradients, glassmorphism, or overly flashy UI

- Use a sophisticated neutral color palette

- Strong visual hierarchy

- Make the property photos the main visual focus

HOME PAGE:

1. HERO SECTION

Create a large full-width property image hero.

Overlay:

- Property name

- Location

- Short tagline

- "Book Your Stay" primary button

- "Explore Property" secondary button

Include a floating booking/search card near the bottom of the hero with:

- Check-in

- Check-out

- Guests

- Check availability button

2. PROPERTY HIGHLIGHTS

Create a clean section showing:

- Guest capacity

- Bedrooms

- Beds

- Bathrooms

- Property type

3. AMENITIES

Display amenities using elegant icons and short labels.

Examples:

- Wi-Fi

- Air conditioning

- Kitchen

- Smart TV

- Swimming pool

- Parking

- 24/7 security

Include a "View all amenities" button.

4. PHOTO GALLERY

Create a premium masonry-style photo gallery.

Use large images and allow users to open a fullscreen gallery/lightbox.

5. ABOUT THE PROPERTY

Create a two-column section:

- Property image

- Description

6. LOCATION

Show the property's location with:

- Map

- Nearby attractions

- Restaurants

- Shopping

- Transportation

7. GUEST EXPERIENCE

Create a section explaining what guests can expect before, during, and after their stay.

8. REVIEWS

Create a clean testimonial/review section.

Show:

- Overall rating

- Guest reviews

- Guest names

- Stay information

9. HOUSE RULES

Show the most important rules in a clean card layout.

10. FINAL BOOKING CTA

Create a visually strong section:

"Ready for your stay?"

with a "Book Your Stay" button.

11. FOOTER

Include:

- Property name

- Contact information

- Location

- Social media

- House rules

- Privacy policy

- Terms

BOOKING PAGE:

Create a dedicated booking page with:

- Date selection calendar

- Guest selector

- Availability status

- Nightly rate

- Number of nights

- Cleaning fee

- Service fee if applicable

- Total price

- Guest information form

- Booking confirmation

Make the booking process simple and intuitive.

GUEST GUIDE:

Create a dedicated digital guest guide with sections:

- Welcome

- Check-in instructions

- Wi-Fi

- Parking

- Building amenities

- House rules

- Things to do nearby

- Checkout instructions

- Key return instructions

- Emergency/contact information

ADMIN DASHBOARD:

Create the UI structure for an admin dashboard where the property owner can later manage:

- Reservations

- Guests

- Availability

- Pricing

- Property information

- Guest messages

TECHNICAL REQUIREMENTS:

- React + TypeScript

- Tailwind CSS

- Responsive design

- Reusable components

- Clean component architecture

- Accessible UI

- SEO-friendly structure

- Use placeholder property images for now

- Do not hardcode the final property information

- Structure the project so Supabase can be integrated later
